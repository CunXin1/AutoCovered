# 持仓报告模板(唯一交付文件的固定骨架)

**一次分析 = 一个文件。** 路径固定 `state/analysis/YYYY-MM-DD-positions-report.md`,
同一天重跑**覆盖**它。**禁止**再按标的另存 `*-<TICKER>-open-research.md` 之类的附属文件 ——
9 维决策表是本报告的第三节,不是单独的文件。要看历史按日期找。
(English edition: `report-template.en.md`,改动时两版同步。)

下面是骨架。`<...>` 是占位符,每节标题下的斜体行是**写作要求**(写进报告时删掉斜体行本身)。
没有内容的节:第五节(数据问题)可整节省略;其余各节必须在,哪怕只有一句"本轮无"。

## 长度预算(硬规则)

报告是给人看的,不是给人存的。**写完 `wc -l` 数一遍,超了就砍。**

- **全文 ≤ 350 行**(含表格行)。实测基线:6 个未覆盖标的 + 1 条在世腿 = 348 行
  (2026-10-05 那份)。标的更多时按**每多一个标的 +28 行**放宽,**硬上限 450 行**
- **第三节每个标的 ≤ 28 行**。这 28 行里 9 维表 11 行 + 候选集表 5–7 行是**底盘**,
  压不动;要省就省散文(结论 / 合成 / 反方 / 代价 / 跨财报披露 合计 ≤ 5 行,每条 1 行写完)
- 其余各节上限:摘要 ≤ 20 · 数据口径 ≤ 10(不超过 5 条 bullet)· 第一节每条腿 ≤ 40 ·
  第二节 ≤ 40 · 第四节 ≤ 18 · 第五节 ≤ 12 · 第六节 ≤ 45
- 装不下时的优先级(从高到低):**摘要表 > 第二节的数字表 > 第三节的 9 维表 > 散文**
- **同一事实只写一次**:摘要表已给的合约/张数/限价/年化,第二、三节只引用不重列;
  第二节**不再单独放"建议卖的合约"表**(它就是开头的摘要表);第一节的纪律线与
  决策点**合成一张表**(阈值 / 现值 / 到那天做什么),不要拆成两张
- **税务占一列 + 一行,不占一节**:被叫走利得与短期/长期进第二节总览表的最后两列,
  合计写一行,摘要里写一行 —— 不写段落、不在每个标的下重复(它对每个候选档都一样)
- **禁止在报告里复述本 skill 的规则条文**("规则:IVR<20 → ↑strike + 减张" 之类)。
  只写这个标的的发现与结论 —— 规则在 skill 里,读报告的人不需要再学一遍
- 9 维表"发现"列每格 **≤ 1 句**;"投票"列 = 票名 + 不超过 6 字的括注
- 候选集表只留**被选中档 + 2–4 个对照档**(被维度 8 否决的保留 1–2 行标 ❌,
  让人看见选择范围有多窄),不是把脚本输出整张贴进来
- 三选项表、决策点表、待决策表每格 **≤ 1 句**
- **散文连续多行时写成 `- ` bullet**,不要堆成一段 —— 相邻的 `**合成**:` / `**反方**:`
  如果不加 bullet,markdown 会把它们渲染成一整段,读的人分不开

## 写报告时的自检清单

- [ ] **全文 ≤ 350 行**(写完真的数一遍:`wc -l`;每多一个标的 +28,硬上限 450),超了先砍散文
- [ ] **摘要表在最前面**(紧跟一句话总结),第二、三节没有重列合约/张数/限价
- [ ] 报告里**没有**复述 skill 的规则条文,只有这些标的的发现与结论
- [ ] 只写了**一个**文件,路径 `state/analysis/YYYY-MM-DD-positions-report.md`
- [ ] 第一行是一句话总结;聊天回答里也是一句话总结 + 关键数字 + 文件路径,**不整篇复述**
- [ ] 每个未覆盖仓位都落到一个**具体合约**(strike / 到期 / 张数 / 限价),没有"不卖"
- [ ] 每个标的的 9 维表在**第三节**,不在单独文件里
- [ ] 跨财报的建议都有 `earnings_moves` 的 p85 与击穿率,不是自己估的
- [ ] 任何 strike ≤ avg_cost 都附了锁损账(含 FIFO 提醒);没有就明写"本轮无"
- [ ] 税务只在总览表的一列 + 摘要/合计各一行,**没有单独的税务节或税务段落**
- [ ] 在世腿给了三选项框架,没有默认推荐 roll
- [ ] 所有数字都能指回 positions.json 或某个确定性脚本;WebSearch 只用于叙述性事实
- [ ] 账本数字给了 round + roll 链两套口径与数据质量分层
- [ ] 本 skill **不推送手机**(推送是 scheduled-tasks 的事)
