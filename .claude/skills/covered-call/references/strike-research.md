# Covered Call Strike 研究框架(9 维决策法)

开仓流程第 3 步的执行手册。delta 只回答"被叫走概率多大",不回答"这只股票
**此刻值不值得**卖、卖在**哪个价位之上**才不后悔"。以下 9 维逐一研究后合成决策。

**分工铁律**:机械层(delta 区间、OTM、DTE>30、不跨财报、覆盖率、net credit)
已由引擎和 propose 护栏强制执行,你不用也不许重新计算;研究层的工作是
**在确定性候选集内部选择,或得出"这轮不卖"**。研究不能发明集外合约——护栏会拒绝。

每一维:查什么 → 从哪查 → 怎么动决策(↑strike=更远/更安全,↓DTE=更短,
减张=部分覆盖,SKIP=这轮不卖)。

---

## 1. IV 水位(卖得贵不贵)— 最重要的一维

- **查**:当前隐含波动率处于自身历史什么分位(IV Rank / IV Percentile)。
  卖 covered call 本质是卖波动率,IV 低位卖 = 贱卖。
- **源**:WebSearch「TICKER implied volatility rank」(Barchart/Market Chameleon
  有公开数据);候选表的年化列是最终落地数字。
- **规则**:IVR < 20 → 收的钱不值得冒封顶风险,**SKIP 或减张**;
  IVR 20–50 → 正常执行;IVR > 50(常见于事件前)→ 积极卖,可用同等权利金
  买到更远的 strike(↑strike)。

## 2. 财报与事件日历(炸点在哪)

- **查**:下一次财报日(务必复核,日期常改且各源不一)、产品发布/投资者日/
  指引更新;高 beta 股加查 FOMC/CPI 日期。
- **源**:positions.json 的 events 字段 + WebSearch 交叉验证。
- **规则**:跨财报到期**默认不选**;引擎的例外通道(delta ≤ earnings_max_delta
  且距现价 ≥ earnings_min_otm_pct,候选表 ⚠️ 列)只在"不跨财报就无候选可用、
  且权利金过维度 9 底线"时才考虑,并在结论里显式标注跨财报风险
  (财报 gap 可以一夜吃掉 20% 距离,极低 delta ≠ 零概率);
  财报日期未官宣的(如各源打架)→ 视为整个窗口都有雷,倾向 SKIP。

## 3. 除息日(提前指派的暗门)

- **查**:expiry 前有没有 ex-dividend date;股息金额 vs 候选的时间价值。
- **源**:WebSearch「TICKER ex-dividend date」;positions.json events.ex_div。
- **规则**:除息在到期前且股息 > 届时预估时间价值 → 提前指派风险实质化,
  选**除息前到期**或 ↑strike 拉开距离(MSFT 这类分红股必查)。

## 4. 技术阻力位与 52 周高点(strike 放在墙后面)

- **查**:现价上方最近的强阻力:52 周高点、前高平台、大整数关口。
- **源**:WebSearch「TICKER 52 week high / resistance」——只用可查证的公开
  价位(52 周高点是事实),禁止自己画线编价位。
- **规则**:strike 尽量放在**强阻力之上**(墙帮你挡);候选 strike 恰好卡在
  前高下方一点 → 上移一档(那是磁铁位,最容易被打穿);
  股价刚创历史新高、上方无阻力 → 没有墙可借,↑strike 并减张。

## 5. 趋势状态(别在火车头前面卖票)

- **查**:近 1–3 个月是突破上行、区间震荡还是回落企稳;是否刚发生
  gap-up/业绩 beat 后的动量延续。
- **源**:WebSearch 近期走势报道 + 52 周高点距离(候选表"距现价"列是事实锚点)。
- **规则**:**强上升趋势 = covered call 最差的时机**(参考 roll 追不上暴涨的
  数学),→ SKIP 或减张 + ↑strike;横盘震荡 = 最佳时机,正常区间内选;
  阴跌中 → 先核对维度 7 的成本价约束再说。

## 6. 分析师目标价与已知催化剂(市场认为它能到哪)

- **查**:主流卖方一致目标价(中位数)、近 2 周有无密集上调评级、
  未来 1–2 个月已知催化剂(新品、大会、行业数据)。
- **源**:WebSearch「TICKER analyst price target consensus」——引用公开发布的
  数字并注明来源,禁止自行估计。
- **规则**:一致目标价比现价高 >20% 且候选 strike 低于目标价 → ↑strike 或减张;
  目标价密集下调/催化剂真空 → 可在区间内选偏近的 strike 多收权利金。

## 7. 成本价与税务(你自己的账,别人替代不了)

- **查**:strike 与持仓成本的关系;距长期资本利得天数;本批持仓的税务状态。
- **源**:positions.json 的 stock.avg_cost 与 metrics.days_to_long_term —— 唯一来源。
- **规则**(硬):**strike 必须 > avg_cost**,否则被叫走 = 锁定亏损,任何权利金
  都不值(CRWV 现在就卡这条);days_to_long_term < DTE 且浮盈可观 →
  被叫走会把长期税率变短期,↑strike 或 SKIP 等过线;QCC(OTM+DTE>30)引擎已管。

## 8. 流动性(进得去还要出得来)

- **查**:候选合约的 bid/ask 点差、未平仓量。将来 roll/买回都要再过一次点差。
- **源**:候选表的 bid/ask 与点差% 列(确定性);OI 可 WebSearch 补充。
- **规则**:点差 > 10% → 换相邻 strike 或标准月度到期日(流动性最好);
  点差 > 20% → 该合约不碰。限价单一律挂 mid 附近,绝不市价。

## 9. 年化收益底线(这轮值不值得做)

- **查**:经过 1–8 维调整后,最终候选的年化收益率(候选表"年化"列)。
- **源**:候选表,唯一来源。
- **规则**:设底线——超低 delta 策略下建议 **年化 < 4% 就 SKIP**(封顶风险
  换不回像样的钱,等 IV 回升再卖)。**"这轮不卖"是合法且常见的正确结论**,
  空手等待不是失败。

---

## 合成决策(固定程序)

1. 跑候选脚本拿确定性候选集(必要时两种 --style 各跑一次)。
2. 按上表逐维研究,每维给出:发现(一句话)+ 来源 + 投票
   (↑strike / ↓DTE / 减张 / SKIP / 中性)。
3. 合成:**任何一维触发硬规则(strike≤成本、点差>20%、年化<底线)→ 直接
   SKIP 或换候选**;≥2 维投 SKIP → 本轮不卖;否则从候选集选出满足最多
   ↑strike 票的那一档,DTE 取 31–45 为默认(theta 衰减最陡),除非维度 2/3
   要求更短。
4. 输出**决策表**(模板见下)+ 最终结论:(strike, expiry, contracts, 限价)
   或 SKIP + 复查条件。给出反方观点(哪一维最可能让这个决定后悔)。
5. 用户确认后才走 propose CLI;你到决策表为止。

### 决策表模板

```
| # | 维度 | 发现 | 来源 | 投票 |
|---|------|------|------|------|
| 1 | IV 水位 | IVR 34,中位 | Barchart | 中性 |
| 2 | 财报 | 10/28,已避开 | 引擎+复核 | 中性 |
| ... |
结论:卖 <expiry> $<strike>C ×<n>,限价 <mid 附近>(年化 x.x%)
反方:若维度5的突破延续,strike 距离只有 +x%,两周内可能进 TESTED
```

## 与系统其它部分的衔接

- 所有价格/delta/年化数字只能来自候选表;WebSearch 只提供**事件与可查证的
  公开事实**(财报日、除息日、52 周高点、目标价),不提供价格计算。
- 研究结论必须落在候选集内;想要集外合约 = 回去改 --style 或改 config,
  不是绕护栏。
- 决策表全文存档到 `state/analysis/YYYY-MM-DD-<TICKER>-open-research.md`,
  推送手机时正文即决策表摘要。
